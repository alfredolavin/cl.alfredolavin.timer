# Nerd Timer — Plasma 6 panel timer

Panel widget showing the timer closest to finishing: icon, name, gradient progress bar with
contrast-aware time, and bordered play/pause, delete, "other running timers" (↑) and "start timer" (+) buttons.

Besides timers (a duration) there are alarms (a time of day: they count down from when they are started to
the next time the clock shows that time). The bottom of the popup starts a one-off timer or alarm
immediately: `2` (hours), `+1h30`, `90s` for timers; prefix `-` for an alarm: `-14:30`, `-7pm`, `-3.5` (3:30: the dot is a decimal fraction of an hour), `-3,5` (3:05: the
comma gives the minutes), `-3,53` (3:53). Without am/pm, an hour from 1 to 11 is read in the 12-hour clock with the current
am/pm: past noon, `-3.5` is 15:30. Bare numbers are hours.

## Install / update

    kpackagetool6 -t Plasma/Applet -i .     # first time
    kpackagetool6 -t Plasma/Applet -u .     # after changes
    plasmoidviewer -a .                     # quick test without a panel

## Layout

- `contents/ui/main.qml` – state: running timers (persisted in `runningState`), ordering, alarms
- `TimerFrame.qml`, `GradientBar.qml`, `IconButton.qml` – the panel widget pieces
- `configAppearance.qml`, `configBar.qml` (shadows: the shared `textspec/TextShadowListEditor`), `configTimers.qml`,
  `ConfigGradients.qml` – settings; every control holds the icon of its setting (the shared `controls/`)
- `gradientpicker/code/gradients.js` (shared) – CSS gradient parser/writer (hex/rgb/hsl/oklch/oklab, `in oklch … hue` interpolation, color hints);
  your gradients are the built-in presets. The editor stores its list back as CSS in `gradientsCss`
- `bundledicons/` (shared) – 300 bundled icons (`icons.js`: names, categories and SVG outlines in one file), drawn
  in any color by `SvgIcon`, chosen with `BundledIconPicker` / `BundledIconChooserButton` (over the shared
  `iconpicker/`); no font needed. Generated by `plasmoids/shared/tools/gen_svg_icons.py` (needs `fonttools`)
  from a Nerd Font's Material Design (Apache 2.0) and Font Awesome Free (CC BY 4.0) glyphs; edit it there
- `contents/fonts/Rubik.ttf` – Rubik variable font (SIL OFL, `OFL.txt`) cut down to Latin by `tools/gen_font.py`;
  all text inside the progress bars uses it, drawn by `common/OutlinedText.qml` with a configurable weight, color and outline
- `code/colorspec.js` + `ColorSpecButton.qml` (over the shared `common/SourceColorButton`) – every color setting is a
  fixed color, a system color or the active gradient's begin, end or current-fill color, adjusted in OKLCH (luminosity, chroma, hue offset) and opacity. The control itself
  (button, editor window, strips, swatches) is the shared `colorspec/` library, copied from `plasmoids/shared/`
  by `shared/sync.sh`; edit it there, not here. Plain stored colors still read as fixed colors
- `AlarmSilencer.qml` – while a timer is finished, any click on the widget stops the alarm and removes the finished timer
- `contents/sounds/*.wav` – generated by `tools/gen_sounds.py` (needs `numpy`)

## System colors

Every configurable color can also take one of the Plasma color scheme's colors (text, background, highlight, link, positive, negative…) as its source, and it still accepts the luminosity, chroma and opacity adjustments. These follow the scheme live when it changes.
